    还没有只读账号？

    把这段跑一遍，护栏做在数据库层

    PostgreSQL

    CREATE ROLE askdb_ro LOGIN PASSWORD '***';

GRANT CONNECT ON DATABASE ragforge TO askdb_ro;
GRANT USAGE   ON SCHEMA public   TO askdb_ro;

-- 只授白名单表，绝不用 ALL TABLES
GRANT SELECT ON documents, knowledge_bases,
                 orgs, model_usage TO askdb_ro;

-- 三道数据库级硬护栏
ALTER ROLE askdb_ro SET default_transaction_read_only = on;
ALTER ROLE askdb_ro SET statement_timeout = '8s';
ALTER ROLE askdb_ro CONNECTION LIMIT 3;
    就算应用层校验被绕过，数据库这边也执行不了 —— 双保险。

    选择开放的表

    白名单既是安全边界，也是准确率边界 —— 只开你真正会问的表
