◇ 为什么这里不给填连接串
askdb 不设账号体系，数据库连接本身即权限边界。 表白名单、租户隔离、业务口径都是跟着这份连接配的 —— 页面若能改连接， 等于任何打开页面的人都能把这套护栏整体换掉。 换数据源请换配置文件后重启，见右侧。

换一个数据源

一个数据源 = 一份配置，用启动参数切换，不改文件

python -m askdb.cli serve \
  -c config/askdb.yaml         # 本机样例库
  -c config/ragforge.yaml      # 本机 PG
  -c config/ragforge-prod.yaml # 云上 PG
每份配置自带配套的 *-tables.yaml 与 *-metrics.yaml —— 白名单和业务口径是跟着库走的，所以换源不可能只换一个连接串。 密码只从环境变量读，不进配置文件。

        场景机制现状

              本页「复放」与 askdb replay，已可用

              检查点随每次提问落 SQLite，已可用
        
          
        断点续跑从最后完成的超步继续，预算计数一并恢复
              设计已定版（任务中断恢复 V1.1），落地前先修 R-17 计数器复位
        
                
      
        
      
        边界：已发生的副作用不随回退撤销；预算计数必须入图状态，否则续跑绕穿上限；
      回放还原的是判定现场，不承诺数据新鲜度。
